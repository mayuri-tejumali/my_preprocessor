# my_preprocessor
About the Project
This project implements a simple C Preprocessor using C programming. It performs basic preprocessing operations on a given C source file before compilation.

Features
Comment Removal: Removes single-line (//) and multi-line (/* */) comments.
Header File Inclusion: Reads and includes standard header file contents.
Macro Replacement: Replaces defined macros with their corresponding values.

Project Files
main.c – Main program that controls the preprocessing steps.
comment_removal.c – Removes comments from the source file.
header_inc.c – Handles header file inclusion.
macro_rep.c – Performs macro replacement.
header.h – Contains header files and function declarations.
makefile – Compiles the project files.

Compilation
Run the following command:
make

Execution
./mypreprocessor input.c
Replace input.c with your C source filename.

Output
The preprocessed code is generated in an output file with the .i extension.

Technologies Used
Programming Language: C
Operating System: Ubuntu Linux
Editor: Vi Editor

Compiler: GCC
